# SampleHyperStore

A dummy retail dataset, generated with Claude Code, for trying AI-driven data analysis on Tableau: tables of a fictional US retailer, 19 business questions, and the assets to set it up on Tableau Cloud with an AI agent.

Claude Code で作成した、架空の小売企業のダミーデータセットです。Tableau で AI によるデータ分析を試すために作りました。架空の米国小売企業のテーブル、19 の業務の問い、AI エージェントで Tableau Cloud にセットアップするための資産をまとめています。

| Edition | Folder | Notes |
|---|---|---|
| English | [`en/`](en/) | The source edition. Includes the generator and the setup scripts. |
| 日本語 | [`ja/`](ja/) | 英語版の翻訳。列名・値・説明を日本語にした版で、数値は英語版と同一。セットアップには `en/setup/` のスクリプトを使う。 |
