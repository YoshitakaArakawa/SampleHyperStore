# SampleHyperStore

A synthetic retail dataset for trying AI-driven data analysis on Tableau: 24 tables of a fictional US retailer, 40 business questions, and the assets to set it up on Tableau Cloud with an AI agent.

Tableau で AI によるデータ分析を試すための合成の小売データセット。架空の米国小売企業の 24 テーブル、40 の業務の問い、AI エージェントで Tableau Cloud にセットアップするための資産をまとめている。

| Edition | Folder | Notes |
|---|---|---|
| English | [`en/`](en/) | The source edition. Includes the generator and the setup scripts. |
| 日本語 | [`ja/`](ja/) | 英語版の翻訳。列名・値・説明を日本語にした版で、数値は英語版と同一。セットアップには `en/setup/` のスクリプトを使う。 |
